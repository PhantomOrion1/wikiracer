Wiki race alternatives

There are a few good ways to play the Wikipedia game online. They suit different players, so here's an honest look at how they differ. Features change, so check each site for what it offers today.

Kinds of wiki race games

TypeWhat it's likeExamples
Shared timed roundsEveryone online gets the same pair each round and a global leaderboardThe Wiki Game (thewikigame.com)
Daily puzzleOne pair per day, Wordle-stylewikiracer.com, the WikiRacer Live daily
Live rooms with friendsPrivate room, invite link, race together in real timeWikiRacer Live
Shortest-path findersNot a game: shows the shortest known route between two articlesSix Degrees of Wikipedia (sixdegreesofwikipedia.com)
Do it yourselfOpen Wikipedia in browser tabs and race on the honour systemAny browser

What WikiRacer Live is good at

  • Playing with people you know. Private rooms for up to 8, a 5-letter code, and a shared start so everyone races at once.
  • No sign-up. Type a name and play. No accounts, ads or cookies.
  • Fair results. Search and Find in page are disabled, leaving the tab is penalised, and every multiplayer route is re-checked against Wikipedia's real links.
  • Seeing how others did it. The results screen compares every player's full route, and you can spectate once you've finished.
  • Pairs you can actually solve. Easy, Medium and Hard pairs are picked from familiar topics, not obscure stubs.

When another option might suit you better

  • If you want a large public leaderboard with thousands of strangers each round, a shared-round game is a better fit.
  • If you want to check the theoretical shortest route after a race, use a path finder like Six Degrees of Wikipedia.
  • If you want non-English Wikipedia, WikiRacer Live currently uses English Wikipedia only.
