Wikirace

Get from one Wikipedia article to another using only the links on the page. Fewest clicks wins.

Solo

Pick a difficulty and beat your personal best.

Duel

Race friends live on the same start and target. Up to 8 players.

How to play
  • You start on one article and need to reach the target article.
  • Only links inside the article count — no search bar, no external links, no category or file pages.
  • Every page change is one click, including the in-game Back button.
  • Lowest clicks wins. Ties are broken by time.
  • In a duel everyone gets the same pair and you can watch each other's progress live.

Articles load live from Wikipedia (CC BY-SA).
